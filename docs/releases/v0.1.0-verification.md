## Architecture

Verdict: the merged export matches the accepted architecture.

[ADR 0051](../adr/0051-remediation-queue-export.md) is Accepted. The composed route is owner and admin `POST /remediation-queue/export`. JSON uses `remediation_queue_export_v1`. The CSV header is the 22 columns in the ADR section 10 order. Formula neutralization prefixes a text cell that begins with `=`, `+`, `-`, `@`, tab, or carriage return. One PostgreSQL `REPEATABLE READ` transaction is the snapshot. The cap is 150 Findings, and a larger population fails closed with no truncation and no audit row. Sections stay separate: ranked, then incomparable, then not calculated. A missing priority is an empty calculated cell, never P4. A human-review corrected band is a review field and does not rank the row. One successful export inserts one `export.created` audit row. A failure before commit rolls the transaction back and leaves no new audit row and no file. Export does not import or run `@patchpilot/policy-engine`. The file is server-generated. The fixed names are `remediation-queue.json` and `remediation-queue.csv`.

This is committed-repository evidence plus inspected tests, not a claim that the architecture agent ran the suite. The inspected sources are [ADR 0051](../adr/0051-remediation-queue-export.md) section 10, `apps/api/src/remediation-queue-http.ts`, `apps/api/src/remediation-queue-http.test.ts`, `apps/api/src/remediation-queue-routes.ts`, `apps/api/src/remediation-queue-routes.test.ts`, `packages/database/src/remediation-queue-persistence.ts`, `packages/database/src/remediation-queue-persistence.integration.test.ts`, `packages/domain/src/risk/remediation-queue.ts`, `packages/domain/src/risk/remediation-queue.test.ts`, `packages/domain/src/risk/remediation-queue-port.ts`, and `apps/web/e2e/release-smoke.spec.ts`.

## Boundary

The working tree implements [ADR 0051](../adr/0051-remediation-queue-export.md) as owner and admin `POST /remediation-queue/export` and the Export JSON and Export CSV controls on `/remediation-queue`. The CSV has the 22 columns in the ADR table. The session spec's "23-column" sentence was treated as a counting error.

The snapshot is one PostgreSQL `REPEATABLE READ` transaction. It classifies the whole organization with the existing queue orders, serializes the exact response bytes inside the transaction, and inserts one `export.created` audit row. Bytes are sent only after commit and are not stored. A population above 150 returns HTTP 409 and writes nothing. A duplicate correlation id returns HTTP 409 and does not resend. A client disconnect after commit can leave an audit row that does not prove receipt.

No migration was added. The frozen migration count stays 28. No production dependency was added. `@playwright/test@^1.64.1` is a root devDependency.
